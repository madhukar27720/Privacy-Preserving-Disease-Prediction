# Privacy-Preserving Federated Learning with Explainable AI for Disease Prediction

## Overview

This project predicts heart disease using Machine Learning while demonstrating Federated Learning concepts and Explainable AI.

## Features

- Heart Disease Prediction
- Streamlit Dashboard
- Federated Learning using Flower
- Explainable AI using SHAP
- LIME Explanations
- Random Forest Classifier
- GitHub Ready

## Technologies

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy
- SHAP
- LIME
- Flower

## Installation

```bash
pip install -r requirements.txt
```

## Train Model

```bash
python train.py
```

## Run Dashboard

```bash
streamlit run app.py
```
